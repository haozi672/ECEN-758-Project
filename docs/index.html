Acoustic Scene Classification Project

Overview

This project implements multiple machine learning and deep learning pipelines for the TAU 2019 Acoustic Scene Classification dataset. The goal is to classify audio recordings based on their environment (e.g., street, bus, airport, home, etc.).

Core Components

  • Classical ML models: Support Vector Machine (SVM) and Random Forest.
  • Deep Learning model: Convolutional Neural Network (CNN) trained on log-mel spectrograms.
  • Feature extraction: Log-mel spectrograms computed using Librosa.
  • Augmentation: Custom waveform-level augmentation pipeline.
  • Configuration system: Centralized hyperparameter and path management.

Project Structure

config.py     - Central configuration for features, models, paths
models.py     - SVM, Random Forest, and PyTorch CNN definitions
train.py      - Training script for SVM and Random Forest
CNN_train.py  - Training loop for Convolutional Neural Network
augment.py    - Waveform-level augmentation utilities
features.py   - Feature extraction helpers
cv_search.py  - Parameter grid search for classical models

Data Processing

Input audio files are resampled to a fixed sampling rate and converted into log-mel spectrograms. Each spectrogram is normalized and padded/cropped to a fixed time dimension so it can be fed into the neural network.

The CNN Model

The CNN is designed to learn time-frequency patterns typical of acoustic scenes. The architecture includes:

  • 3 convolutional blocks (Conv → BatchNorm → ReLU → MaxPool)
  • A fully connected classifier head
  • Dropout for regularization

The model predicts probabilities for all scene categories.

Training Workflow

  1. Load metadata and perform grouped train/test split.
  2. Apply data augmentation (training only).
  3. Extract log-mel spectrograms.
  4. Train CNN for a configurable number of epochs.
  5. Save the best-performing model.

Results & Evaluation

The framework reports:

  • Training and test accuracy per epoch
  • Classification report (precision, recall, F1)
  • Confusion matrix for detailed class-by-class performance

Future Improvements
