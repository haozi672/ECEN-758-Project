Artificial Neural Network Homework – Code Overview

This GitHub Pages site explains the code used to solve two artificial neural network homework problems:

  • Problem 4: Single neuron network (no hidden layer).
  • Problem 5: Network with a single hidden layer.

Repository Files

  • ann_homework_solutions.ipynb – Jupyter notebook with all calculations and outputs.
  • single_neuron.py (optional) – Python script version of Problem 4.
  • hidden_layer_network.py (optional) – Python script version of Problem 5.

You can view the notebook directly on GitHub, or download it and run it locally with Jupyter or VS Code.

Common Functions

Both problems use the standard sigmoid activation function: 

import math

def sigmoid(z: float) -> float:
    \"\"\"Standard logistic sigmoid function.\"\"\"
    return 1.0 / (1.0 + math.exp(-z))

Problem 4 – Single Neuron (No Hidden Layer)

In this problem, the network has two inputs and one output neuron. The forward pass computes the weighted sum and applies the sigmoid: 

# Inputs and parameters
x1, x2 = 2.0, 1.0
w1, w2 = 2.0, -1.0
b1 = 1.0

z = w1 * x1 + w2 * x2 + b1
y1 = sigmoid(z)  # network output

The notebook shows:

  • How to compute the output y1.
  • How the perceptron learning rule behaves (no weight change here because the classification is already correct).
  • How to update w1, w2, and b1 using gradient descent on the squared error E = 0.5 * (d - y1)**2.

Problem 5 – Network with One Hidden Layer

This network has:

  • Two input neurons (x1, x2).
  • Two hidden neurons (h1, h2).
  • One output neuron (y1).

The forward pass in the notebook:

# Hidden layer
z1 = w1 * x1 + w3 * x2 + b1
z2 = w2 * x1 + w4 * x2 + b2

h1 = sigmoid(z1)
h2 = sigmoid(z2)

# Output layer
z3 = w5 * h1 + w6 * h2 + b3
y1 = sigmoid(z3)

Backpropagation is used to compute the gradients and update the weights. For example, the error at the output neuron is: 

E = 0.5 * (d - y1)**2
delta3 = (d - y1) * y1 * (1 - y1)  # output delta

# Example weight update for output weight w5
w5_new = w5 + eta * delta3 * h1

Then the error is propagated back to the hidden layer to update w1 and other weights using their corresponding deltas.

How to Run the Code

  1. Clone the repository: 
    git clone https://github.com/<your-username>/ann-homework.git
cd ann-homework
  2. Create and activate a virtual environment (optional but recommended).
  3. Install Jupyter if needed: 
    pip install jupyter
  4. Start Jupyter: 
    jupyter notebook
  5. Open ann_homework_solutions.ipynb and run all cells.
